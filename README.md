# Hesbah Network Manager

النسخة الأولية من منصة إدارة الشبكات. تركز حاليًا على سجل أجهزة يدوي محلي فقط.

## ما الذي تفعله الآن؟

- إضافة اسم الجهاز ونوعه وعنوان IPv4.
- تعديل وحذف السجلات.
- البحث داخل السجل.
- تعريف اسم الشركة محليًا للواجهة.
- سجل محلي للمشتركين والباقات واسم PPPoE ونوع راوتر العميل.
- سجل عمليات محلي للتغييرات على الأجهزة والمشتركين والإعدادات.
- واجهة اشتراك تمهيدية خاصة بمالك الشركة.
- حفظ البيانات في متصفح المستخدم فقط.
- تشغيل كتطبيق ويب قابل للتثبيت (PWA).

## حدود الأمان الحالية

لا توجد اتصالات بالشبكة، ولا فحص اتصال، ولا فتح لواجهة جهاز، ولا إرسال أوامر إدارة. كما أن كلمات مرور PPPoE لا تُحفظ في المتصفح المحلي. لن تبدأ هذه المزايا قبل إعداد خادم تجريبي ومراجعة آلية الصلاحيات والتشفير وسجل التدقيق.

## التشغيل من GitHub Pages

يتم نشر النسخة الثابتة تلقائيًا إلى GitHub Pages عند كل تحديث على فرع `main` بواسطة GitHub Actions. بعد نجاح مهمة Deploy Hesbah Network Manager، افتح رابط Pages الذي يظهر في تفاصيل المهمة. يمكن تثبيت التطبيق من المتصفح بعد النشر عبر HTTPS.

## التشغيل المحلي

افتح `index.html` في متصفح حديث. للتثبيت كتطبيق، شغّله من خادم ويب محلي بسيط ثم استخدم خيار التثبيت في المتصفح.
